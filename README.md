# X/Twitter Home Clone

A responsive X/Twitter-inspired home page built using HTML, Tailwind CSS, and JavaScript.

## 🚀 Live Demo

https://x-twitter-home.netlify.app/

## 🛠️ Built With

- HTML5
- Tailwind CSS
- JavaScript
- Netlify

## ✨ Features

- Responsive layout
- X/Twitter-inspired interface
- Navigation sidebar
- Post/feed interface
- Responsive mobile layout
